# EXDIA Real Estate Platform

واجهة تأسيسية عربية RTL لمنصة إدارة EXDIA، مبنية باستخدام Next.js وTypeScript ومخطط قاعدة بيانات PostgreSQL عبر Prisma.

## الموجود في هذه النسخة
- لوحة تحكم عربية بتصميم كحلي وذهبي.
- صفحة تأسيسية لإدارة العقارات.
- نقطة فحص `/api/health` تعرض هل متغير `DATABASE_URL` مضبوطًا فقط؛ لا تؤكد الاتصال الفعلي.
- مخطط PostgreSQL يشمل المستخدمين والأدوار والملاك والعملاء والعقارات والصفقات والعمولات والمصروفات.
- لا توجد بيانات عقارية وهمية أو كلمات مرور افتراضية.

## ما لم يتم تفعيله بعد
هذه نسخة تأسيسية وليست منصة إنتاج مكتملة: تسجيل الدخول الآمن، صلاحيات الخادم، عمليات CRUD للعقارات، رفع الصور، صفحات بقية الأقسام، وسيناريوهات الاختبار تحتاج إلى تنفيذ قبل استخدامها فعليًا. لا تُدخل بيانات عملاء حقيقية قبل إكمال المصادقة والصلاحيات.

## المتطلبات
- Node.js 20 أو أحدث
- قاعدة PostgreSQL متاحة

## التشغيل محليًا على Windows
1. ثبّت Node.js إصدار LTS من الموقع الرسمي: https://nodejs.org/
2. فك ضغط المشروع وافتح مجلده في VS Code.
3. افتح Terminal داخل VS Code وشغّل:

   ```bash
   npm install
   ```

4. انسخ `.env.example` إلى ملف جديد اسمه `.env`، ثم ضع رابط قاعدة PostgreSQL الخاص بك داخل `DATABASE_URL`. لا ترفع `.env` إلى GitHub.
5. أنشئ الجداول في قاعدة البيانات التي اخترتها:

   ```bash
   npx prisma generate
   npx prisma db push
   ```

   **تنبيه:** تأكد من أن `DATABASE_URL` يشير إلى قاعدة جديدة/مخصصة لهذا المشروع قبل تنفيذ `db push`. لا تستخدم عنوان قاعدة مشروع قائم يحتوي بيانات مهمة.

6. شغّل الموقع:

   ```bash
   npm run dev
   ```

7. افتح `http://localhost:3000`.

## فحص الإعداد
افتح `http://localhost:3000/api/health`. القيمة `databaseConfigured` تعني فقط أن متغير البيئة موجود، وليست اختبارًا لاتصال PostgreSQL.

## النشر
يمكن نشر التطبيق على Vercel بعد إعداد متغيرات البيئة وقاعدة PostgreSQL. لا تنشر قبل تنفيذ المصادقة والصلاحيات وواجهات حفظ البيانات واختبارها.

## ربط الموقع العام
لا تغيّر الموقع الحالي `https://exdia-real-estata.vercel.app/` ولا تحذف العقارات الثمانية القديمة في هذه المرحلة. الربط العام يحتاج إلى API منشور ومختبر، ثم تحديث صفحة العقارات بعد التأكد من البيانات والصور وحالات النشر.
